# Тестовая русская локализация

Версия исходников: Mushoku Tensex 0.10.0 (по x-options.rpy).

Файл `game/tl/russian/strings.rpy` содержит переводы интерфейса и вступительной сцены Рокси через стандартный механизм Ren'Py `translate russian strings`.

## Важно
- Это исходный файл локализации, не APK.
- Для проверки нужен проект игры с оригинальными ресурсами и Ren'Py SDK подходящей версии.
- В игре необходимо выбрать язык Russian/Русский в настройках, если меню выбора языка предусмотрено.
- Перевод пока частичный. Сюжетные строки, для которых движок использует сгенерированные блоки перевода, могут потребовать отдельной обработки.
